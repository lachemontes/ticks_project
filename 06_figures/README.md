## `IdeoGram.ipynb`

Prepares the two input files that **MG2C v2.1** (<http://mg2c.iask.in/mg2c_v2.1/>)
needs. MG2C is a web tool, so the notebook stops at the input files — the plot
itself is produced in the browser and exported as SVG.

### Input

- `analysis/miniprot/<LABEL>_miniprot.gff` — from
  [`../04_chromosomal_mapping/`](../04_chromosomal_mapping/)
- `analysis/miniprot/chromosome_lengths_Iric.txt` — same source

### What each cell does

| Cell | Action |
|------|--------|
| 2 | Parses the GFF with pandas. Assigns a colour per feature: `mRNA` → black; `CDS` → red when it is the **first or last** CDS of its parent (i.e. a terminal exon), black otherwise. Writes `output_table_iGluR_IR_2025.csv` |
| 4 | Aggregates to one row per gene — `min(gene_start)`, `max(gene_end)`, `first(chr_id)` — giving the full genomic span of each receptor |
| 6–8 | Documents the samtools route to the chromosome-length table and shows the expected format |

> The colour rule marks terminal exons, which is what makes short single-exon
> alignments visually distinguishable from multi-exon genes on the ideogram.

### Output

| File | Role |
|------|------|
| `output_table_iGluR_IR_2025.csv` | Per-feature table (intermediate) |
| aggregated gene table | **MG2C input 1**: `gene_id`, `gene_start`, `gene_end`, `chr_id`, `gene_color` |
| `chromosome_lengths.txt` | **MG2C input 2**: `chr_id`, `chr_length` |

### Chromosome-length table

```bash
samtools faidx GCA_964199275.3_IXRI_v3_genomic.fna
cut -f1,2 GCA_964199275.3_IXRI_v3_genomic.fna.fai > chromosome_lengths.txt
```

`11_miniprot.sh` already does this — the notebook documents it for
standalone use. Keep only the chromosome-scale scaffolds (`OX3874*` for IXRI_v3);
unplaced contigs clutter the ideogram.

> The paths hard-coded in cells 2 and 7 point at an earlier *Argiope bruennichi*
> analysis (`Spiders_Project/.../GCA_015342795.1`) and the sample length table in
> cell 8 lists `OX3874*` accessions. **Update both to your *I. ricinus* paths**
> before running.
